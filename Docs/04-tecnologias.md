# 04 · Tecnologías y herramientas

## Frontend
| Tecnología | Uso | Por qué |
|---|---|---|
| React | Interfaz por componentes | Permitido por el profesor; reutilización de componentes |
| HTML (JSX) | Estructura de las vistas y formularios | Base de toda la interfaz |
| CSS | Estilos, diseño responsivo | Hojas de estilo por componente |
| JavaScript | Lógica de la interfaz | Validaciones, manejo de estado, llamadas a la API |
| React Router | Navegación entre vistas | Rutas interrelacionadas |
| Vite | Entorno de desarrollo y empaquetado | Arranque rápido |

## Backend y base de datos (Supabase)
| Servicio | Uso |
|---|---|
| Supabase Auth | Registro, inicio de sesión y sesiones |
| PostgreSQL | Base de datos relacional |
| API de Supabase | CRUD de publicaciones, usuarios, etc. |
| Row Level Security | Permisos por rol (visitante, usuario, vendedor) |
| Supabase Storage | Imágenes de las publicaciones |
